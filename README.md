# OutlineNut

OutlineNut is a high-performance machine learning platform that leverages auto-scaling and predictive-analytics capabilities.

The key benefits of using OutlineNut include:

- OutlineNut is a high-performance machine
- learning platform that leverages auto-scaling
- and predictive-analytics capabilities

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/OutlineNut.git`
2. `cd OutlineNut`
3. Install in editable mode: `pip install -e .`

## Configuration

OutlineNut is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
